## What this cost

The entire deployment and the full disclosure cycle, three on-chain UltraHonk
verifications included, consumed **about 0.00000003 ETH** at Horizen's gas price.

| Operation | Gas |
| --- | ---: |
| `publishSurface`, risk surface with ZK verification | 2,364,745 |
| `commitRevision`, revision delta with ZK verification | 2,222,038 |
| `publishSurface`, deteriorated surface | 2,192,403 |
| `settle`, redemption queue | 132,202 |

All five contracts are source-verified on the explorer, so the code running at
these addresses can be read rather than trusted.

## A note on the chain itself

Partway through this work the testnet sequencer stopped producing blocks for
about twenty minutes, froze at block 27,927,778, and then caught up in a burst.
Mainnet kept producing throughout. Nothing was lost, but a deployment in flight
stalls with it, and a pending transaction priced below the base fee cannot be
replaced while the sequencer is down. Worth knowing before anyone schedules a
mainnet cutover around testnet rehearsals.
